# C1 — 触发词与边界

## 标准

skill 的 frontmatter `description` 决定**它能不能在该被触发的场景被触发**。这是 review 必须最先看的一项——`description` 写得不对，下面所有功能都白搭。

## 检查项

- [ ] **触发阈值策略**：review 时先判断该 skill 是“自有业务操作入口”还是“通用能力/外部工具”。前者（如 example-cli 导出/清洗/看板/巡检）应采用 **1% 命中原则**：只要用户请求里出现该业务的核心动作或子模块名，即使缺少项目 ID、字段名、CLI 名，也应先触发 skill，由 skill 内部澄清/补字段/退出；不要让 Agent 因“信息不全”绕去 WebSearch、通用 SQL、通用 BI 等工具。后者仍需精准触发，避免污染上下文。
- [ ] **业务关键词**：含 ≥3 个具体业务名词。例如媒资 example-cli 应包含「媒资」「数据治理」「导出」「清洗」「对账」「巡检」等。**只写「数据」「平台」是不合格的**——和别的 skill 抢不过。
- [ ] **典型短语 / 触发例句**：description 里直接列 ≥1 个用户口语化句式。例：`"导出电视剧频道S+的专辑"`、`"看看最近的清洗任务跑成啥样"`。
- [ ] **动作动词覆盖**：列出该 skill 真正支持的动作动词集合：`查 / 列 / 导出 / 清洗 / 对账 / 同步 / 设置 / 上传`。Agent 路由匹配主要靠动词。
- [ ] **不耦合品牌/路径**：description 与 SKILL 正文都**不得**出现 `~/.box`、`~/.workbuddy`、`~/Library/Application Support/Box` 等任何 Agent 产品私有目录。skill 必须保持平台中立。
- [ ] **触发反例**（可选但推荐）：在 SKILL 顶部「不适用场景」明确列出**不该被触发的 case**，避免乱触发污染。

## 反模式

```text
❌ description: "数据相关任务工具"
   → 关键词太泛，Agent 命中率低，触发的全是误触发。

❌ description: "在 ~/.box/skills 下使用 <cli> 操作 example-cli"
   → 写死了 Box 产品路径，换 Workbuddy 装上就失效。

❌ description: "示例 CLI 工具"
   → 没有业务动词，"导出电视剧 S+ 专辑"这种自然语句完全不会触发。

❌ 自有业务技能只写「当用户明确提到 example-cli/<cli> 时触发」
   → 用户说「导出迪丽热巴主演的电视剧」时，Agent 可能改走 WebSearch。应写明只要出现导出/清洗/看板/巡检等子模块动作且对象可能是媒资数据，就先触发技能。
```

## 正解模板

```yaml
description: 使用 <cli> CLI 操作媒资智能数据治理平台 example-cli，完成数据导出（含 limit、COS 上传）、清洗、对账、巡检等任务。当用户提到数据导出、清洗数据、查看项目字段、设置权限、查询任务状态、"导出电视剧频道S+的专辑"、"看看清洗任务跑成啥样"等媒资数据治理操作时触发。
```

## 1% 命中原则模板（自有业务操作 skill）

适用于团队自有平台/CLI/业务入口，尤其是“触发失败会导致 Agent 去错误工具”的场景：

```markdown
<EXTREMELY-IMPORTANT>
如果用户请求中出现「导出 / 清洗 / 数据看板 / 巡检 / 对账 / 字段 / 枚举 / 上传 / 任务状态」等本业务子模块词，并且对象可能是数据、项目、字段、文件、任务或看板，即使只有 1% 可能属于本业务，也必须先触发本 skill 并在 skill 内澄清/补信息/退出。

不要因为用户没说平台名、CLI 名、项目 ID、字段名就放弃触发；这些信息应在 skill 内通过查询或追问补齐。最终确认不是本业务场景时，再说明无法处理并退出。
</EXTREMELY-IMPORTANT>
```

注意：1% 命中原则不是无边界乱触发，必须配合“不要触发”近似负样本使用。

要素拆解：
- 工具名（`<cli>`）+ 平台名（`example-cli`）→ 显式指代
- 业务动词集合（导出/清洗/对账/巡检）
- 业务对象（专辑/字段/任务）
- 真实口语化触发例句
- 不出现产品/品牌私有路径

## review 时一行命令

```bash
rg -nE 'description:|~/\.(box|workbuddy)|Application Support/Box' skills/<your-skill>/SKILL.md
```
